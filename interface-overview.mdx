# Jarvis HUD Interface: A Complete Visual Guide

The Jarvis interface isn't just a chat window with a coat of paint. It's a fully realized **heads-up display** — a living, animated workspace designed to make interacting with AI feel as powerful as it actually is. This guide walks you through every element, panel, and control so you can navigate the HUD like a pro.

---

## The HUD Overview

When you first log in, the Jarvis HUD assembles on screen with a cinematic boot sequence: glowing arcs sweep outward from the center, a hexagonal grid materializes behind the panels, and status indicators light up one by one as subsystems come online.

The design draws direct inspiration from the Iron Man universe's **FRIDAY and JARVIS** interfaces — the same aesthetic language of neon-lit panels, arc-reactor blue accents, and information-dense displays that feels simultaneously futuristic and immediately intuitive.

Key visual elements you'll notice throughout the HUD:

- **Glowing arc borders** — The outer edges of each panel pulse gently, indicating the system is active and responsive.
- **Animated grid lines** — A subtle geometric grid underlies the workspace, shifting slightly as Jarvis processes requests.
- **Color-coded status lighting** — At a glance, you always know what Jarvis is doing (see [Status Indicators](#status-indicators) below).
- **Fluid transitions** — Panels open, close, and update with smooth animations rather than jarring snaps.

<Note>
  If you prefer a less animated experience, you can reduce motion effects in **Settings → HUD Theme → Motion Intensity**. All functionality remains identical.
</Note>

## Chat Panel

The **Chat Panel** is your primary text interface with Jarvis — the place where you type, send, and review your side of the conversation.

**Location:** Left-center of the HUD on desktop; full-width at the bottom on mobile.

**What you'll find here:**

- **Message input field** — A multi-line text box at the bottom of the panel. Click to focus and start typing immediately.
- **Send button** — The glowing arrow icon to the right of the input field. Or just press **Enter**.
- **Message history** — Your previous messages scroll upward above the input field. Scroll up to review anything from earlier in the session.
- **Formatted output preview** — Jarvis's responses in the chat thread support full markdown: **bold**, *italics*, `inline code`, numbered lists, and more.
- **Code blocks** — Multi-line code responses render in a syntax-highlighted block with a one-click copy button in the top-right corner.

**Multi-line input:** Need to write a longer message or paste in a block of text? Press **Shift + Enter** to add a new line without sending.

<Tip>
  You can paste code, entire documents, or formatted text directly into the chat input. Jarvis handles rich pasted content gracefully — try pasting a snippet of code and asking it to explain or refactor it.
</Tip>

## Voice Activator

The **Voice Activator** is the circular button centered at the bottom of the HUD — and it's one of the most distinctive elements of the Jarvis experience.

**What it looks like:**
A glowing circular button with a microphone icon at its center, surrounded by a pulsing ring animation when active. At rest, it glows a soft arc-reactor blue. When listening, the ring expands and contracts rhythmically, and a live **waveform visualization** appears above it, mirroring your speech in real time.

**How to use it:**

1. **Click once** — Activates voice mode. The ring begins pulsing; the waveform appears. Speak naturally.
2. **Speak your message** — No wake words or special commands. Just talk.
3. **Click again (or pause)** — Deactivates listening. Jarvis processes your input and responds.

<Note>
  The first time you click the Voice Activator, your browser will ask for microphone permission. Click **Allow** — Jarvis cannot hear you without it. This is a one-time prompt per browser/device.
</Note>

**Keyboard alternative:** Press **Ctrl + M** (or **Cmd + M** on Mac) to toggle the microphone on and off without reaching for the mouse.

## Response Panel

The **Response Panel** is where Jarvis speaks. Every reply — whether triggered by text or voice — appears here, rendered with full formatting and delivered with a character-by-character streaming animation that makes responses feel alive rather than static.

**Location:** Right-center of the HUD on desktop; displayed above the chat input on mobile.

**Supported content types:**

| Content Type | How It Renders |
|---|---|
| Plain text | Clean, readable prose with animated streaming |
| Markdown | Bold, italics, headings, lists — all rendered natively |
| Code blocks | Syntax-highlighted, with language label and copy button |
| Tables | Formatted grid layout with alternating row shading |
| Math expressions | Rendered using standard notation formatting |
| Links | Clickable inline hyperlinks, opening in a new tab |

**Copying responses:** Each response block has a **Copy** icon (two overlapping squares) in the top-right corner. Click it to copy the full response text to your clipboard.

## Status Indicators

At the top of the HUD, a row of small **status lights** gives you an at-a-glance readout of what Jarvis is currently doing. You'll never be left wondering why nothing's happening.

| Color | Status | Meaning |
|---|---|---|
| 🟢 **Green** | Ready | Jarvis is idle and waiting for your next input |
| 🟠 **Orange** | Processing | Jarvis is thinking — generating a response |
| 🔵 **Blue** | Voice Active | Microphone is on; Jarvis is listening |
| 🔴 **Red** | Error | Something went wrong — hover for a brief error message |

When the status light is **orange**, you'll also see a subtle loading arc animate around the outer edge of the Response Panel, confirming that a reply is on its way.

## Settings Access

The **Settings panel** is accessible via the **gear icon (⚙️)** in the top-right corner of the HUD. Click it to open a slide-in settings drawer without leaving your current conversation.

Settings are organized into three tabs:

- **Personality** — Adjust Jarvis's tone (Professional ↔ Witty), verbosity (Concise ↔ Detailed), and formality level.
- **Voice** — Choose a voice profile for Jarvis's spoken replies, set playback speed, and configure auto-speak behavior.
- **HUD Theme** — Switch color themes (Arc Blue, Stealth Black, Crimson Mark III, and more), adjust panel opacity, and control motion intensity.

Press **Escape** or click outside the drawer to close Settings without losing your place.

<Tip>
  Explore **HUD Theme → Stealth Black** for a darker, lower-contrast display that's easier on the eyes during late-night sessions. Explore theme options at [HUD Themes](/customization/hud-themes).
</Tip>

## Conversation History

Every conversation you have with Jarvis is automatically saved. Access your history via the **sidebar** (desktop) or **bottom drawer** (mobile), accessible by clicking the **clock/history icon** on the left edge of the HUD.

**What you can do in Conversation History:**

- Scroll through a list of past sessions, sorted by date
- Click any session to reload it in the main HUD — including all messages, formatted responses, and code blocks
- Use the **search bar** at the top of the history panel to find past conversations by keyword
- **Delete** individual sessions using the trash icon that appears on hover
- **Pin** important conversations to the top of your history list for fast access

<Note>
  Conversation history is stored per-account and syncs across all your devices. Start a conversation on desktop and pick it up on mobile without missing a beat.
</Note>

## Navigating: Chat Mode vs Voice Mode

<Tabs>
  <Tab title="Chat Mode">
    In **Chat Mode**, the Jarvis HUD centers around the text conversation flow.

    **How to interact:**
    - Click the Chat Panel input field to focus it
    - Type your message and press **Enter** to send
    - Use **Shift + Enter** for multi-line messages
    - Press **Ctrl + K** to clear the current chat and start fresh

    **Best for:**
    - Detailed, structured requests
    - Pasting in code, documents, or data
    - Conversations where you want a written record
    - Working in environments where speaking aloud isn't practical

    **Tips for Chat Mode:**
    - Use markdown in your messages — Jarvis recognizes and mirrors it in responses
    - Ask follow-up questions without repeating context — Jarvis remembers the full thread
    - Request specific formats: "Give me that as a bullet list" or "Show me the code only"
  </Tab>
  <Tab title="Voice Mode">
    In **Voice Mode**, the HUD shifts its focus to the Voice Activator. The waveform visualization expands, and the Response Panel switches to a larger, more readable display optimized for listening.

    **How to interact:**
    - Click the **Voice Activator button** or press **Ctrl + M** to start listening
    - Speak your message naturally — full sentences work best
    - Pause or click the button again to signal you're done speaking
    - Jarvis responds in both text (Response Panel) and speech (if auto-speak is enabled)

    **Best for:**
    - Hands-free work sessions
    - Quick questions that don't need a written record
    - Thinking out loud and iterating conversationally
    - Accessibility needs or personal preference

    **Tips for Voice Mode:**
    - Speak at a natural pace — you don't need to slow down or over-enunciate
    - If Jarvis mishears you, the transcription appears before it processes — you can correct it in the chat input
    - Enable **Auto-Speak** in Settings → Voice so Jarvis reads its responses aloud automatically
  </Tab>
</Tabs>

## Keyboard Shortcuts

Master these shortcuts to move through the Jarvis HUD at full speed.

| Shortcut | Action |
|---|---|
| `Enter` | Send the current message |
| `Shift + Enter` | Insert a new line (without sending) |
| `Ctrl + M` / `Cmd + M` | Toggle microphone (Voice Mode on/off) |
| `Ctrl + K` / `Cmd + K` | Clear the current chat |
| `Ctrl + /` / `Cmd + /` | Focus the chat input from anywhere |
| `Ctrl + H` / `Cmd + H` | Open / close Conversation History |
| `Escape` | Close Settings, History, or any open drawer |
| `Ctrl + C` / `Cmd + C` | Copy the last Jarvis response (when Response Panel is focused) |

<Note>
  Keyboard shortcuts are active whenever the HUD is in focus. If a shortcut isn't working, click anywhere on the HUD to make sure the browser focus is on the Jarvis window rather than another tab.
</Note>
