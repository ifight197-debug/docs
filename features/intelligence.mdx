## What Powers Jarvis

Behind the HUD and the synthesized voice is a **state-of-the-art large language model** — one of the most capable AI systems available. Trained on an enormous breadth of human knowledge spanning science, technology, literature, law, mathematics, and more, it forms the cognitive engine that makes Jarvis genuinely useful rather than just impressive-looking.

Jarvis is not a search engine. It doesn't retrieve pre-written answers — it **reasons**, **synthesizes**, and **generates** responses tailored to exactly what you asked, taking into account everything you've said in the conversation so far.

## Code Assistance in Action

Jarvis treats code like a first-class citizen. Ask it to write a function, explain an unfamiliar pattern, hunt down a bug, or convert code from one language to another.

```python Example: Jarvis generates a recursive binary search with explanation
# Prompt: "Write a recursive binary search function in Python and explain
# how it works, including time and space complexity."

def binary_search(arr: list, target: int, low: int = 0, high: int = None) -> int:
    """
    Recursively searches for `target` in a sorted list `arr`.
    Returns the index of the target, or -1 if not found.
    """
    if high is None:
        high = len(arr) - 1

    # Base case: search space is exhausted
    if low > high:
        return -1

    mid = (low + high) // 2

    if arr[mid] == target:
        return mid
    elif arr[mid] < target:
        # Target is in the right half
        return binary_search(arr, target, mid + 1, high)
    else:
        # Target is in the left half
        return binary_search(arr, target, low, mid - 1)


# Example usage
sorted_list = [3, 9, 15, 21, 34, 47, 56, 78, 91]
print(binary_search(sorted_list, 47))   # Output: 5
print(binary_search(sorted_list, 100))  # Output: -1

# ─── Complexity ──────────────────────────────────────────
# Time:  O(log n) — search space halves with each recursive call
# Space: O(log n) — call stack depth equals number of halvings
```

Jarvis can follow up on any part of this output — ask it to convert this to an iterative version, add type hints, write unit tests, or explain the stack frame behavior in detail.

## Reasoning & Multi-Step Problem Solving

Jarvis doesn't just answer surface-level questions — it can work through complex, multi-step problems by breaking them down into logical stages. When faced with ambiguous inputs, Jarvis clarifies its assumptions before proceeding, and when a problem has multiple valid approaches, it presents the trade-offs.

Example prompts that showcase Jarvis's reasoning depth:

- *"A train leaves Station A at 60 mph. Another leaves Station B at 80 mph from the opposite direction 150 miles away. When do they meet, and where?"*
- *"What are the architectural trade-offs between event-driven microservices and a modular monolith for a team of 5 engineers?"*
- *"Walk me through Bayes' theorem using a medical test example."*

## Accuracy & Limitations

<Note>
  Jarvis is highly capable, but it is not infallible. Like all large language models, it can occasionally produce incorrect, outdated, or overly confident responses — sometimes called "hallucinations." Always verify critical information (medical, legal, financial, safety-related) through authoritative sources before acting on it. When in doubt, ask Jarvis to explain its reasoning or cite sources — this can help you spot where to double-check.
</Note>

Known limitations to keep in mind:

- **Knowledge cutoff:** Jarvis's training data has a knowledge cutoff date. It may not be aware of very recent events, newly released software, or the latest research.
- **Mathematical precision:** While Jarvis handles most arithmetic and logical reasoning well, complex numerical computations should be verified with a dedicated calculator or code.
- **Opinions vs. facts:** Jarvis can discuss contested or subjective topics, but its responses reflect patterns in training data — not independent judgment or personal experience.
- **Confidentiality:** Do not share sensitive personal data (passwords, financial account details, private health records) in the chat panel.

Jarvis is not static. The underlying model and surrounding systems are **continuously improved** through ongoing research, fine-tuning, and user feedback. Capabilities expand over time, accuracy improves, and new features are added as the technology evolves.

If Jarvis gives you a response that seems wrong, incomplete, or unhelpful, use the **thumbs down** feedback button beneath any message. Your feedback is anonymized and used to improve future responses — you're directly contributing to making Jarvis smarter for everyone.
